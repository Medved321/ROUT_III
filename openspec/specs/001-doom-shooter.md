# 001 Doom-Style FPS Shooter (ROUT III)

## Статус и цель

Серверо-ориентированный шутер в стиле Doom 1 с DDA raycasting.
Сервер — авторитетный (вся логика на сервере). Клиент рендерит и шлёт ввод.
Одиночная игра = один клиент, мультиплеер = несколько клиентов в лобби.

- [x] Сервер: async UDP, тик 20 Гц, лобби + партии (`server/lobby.py`)

## Архитектура

- Сервер `server/server.py`: GameServer ведёт Lobby; `Lobby` содержит `Party` —
  у каждой свой `GameWorld`; state рассылается только членам партии (0x02).
- Клиент `client/client.py`: подключение → лобби → выбор/создание партии →
  вход (Join Accept с картой) → игровой цикл. Esc → Leave Party → лобби.
- Протокол: пакет = `[1B тип][2B seq][payload]`, big-endian, struct. Управляющие
  сообщения обёрнуты в `RELIABLE_DATA` (0x22), игровые — как есть. Версия
  протокола — `PROTOCOL_VERSION` (2); несовместимый клиент к партии не допускается.
- Сервер раздаёт актуальный клиент из `releases/`; клиент применяет его отдельным
  версионным файлом, не перезаписывая запущенный.

## Типы пакетов

| Код | Направление | Назначение |
|-----|-------------|-----------|
| 0x01 | C→S | Player Input |
| 0x02 | S→C | World State (только членам партии) |
| 0x03 | C→S | Join Request |
| 0x04 | S→C | Join Accept (player_id + карта при входе в партию) |
| 0x06/0x07 | C/S | Ping / Pong |
| 0x08 | C→S | Get Lobby |
| 0x09 | S→C | Lobby State (список партий с игроками) |
| 0x0A/0x0B | C/S | Create Party / Party Created |
| 0x0C/0x0D | C/S | Join Party / Join Fail |
| 0x0E | C→S | Leave Party |
| 0x20/0x21 | C/S | Hello / Hello Ack (версия + предложение обновления) |
| 0x22/0x23 | C↔S | Reliable Data / Ack (надёжный канал) |
| 0x24/0x25/0x26 | C/S | File Request / File Data / File Complete (обновление) |

## В игре (плеер)

- Pos(x,y), угол, HP, состояние (жив/мёртв/стрельба) из 0x02.
- Ввод: WASD (движение), мышь (поворот), ЛКМ (стрельба, урон 25 при попадании
  в радиусе 2.0 и угле < 0.5 рад).
- HUD: HP, FPS, ping. Мини-карта: игрок зелёный, враги красные.
