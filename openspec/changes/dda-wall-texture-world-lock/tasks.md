## 2. Проверка

- [x] 2.1 `py -3.12 smoke_dda_wall_texture.py` — тексель читается **из кадра**
      по соотношению каналов маркерной текстуры; одна мировая точка стены даёт
      один тексель из двух соседних точек стояния, и каждый ракурс проверяется
      отдельно против аналитического текселя своего мира.
- [x] 2.2 Проверка «имеет зубы»: с прежним путём (тексель из точки перелёта)
      smoke падает — `view (96.0, 256, 0.0) is not world-locked by itself: 32
      texels off`; отдельный сценарий `_against_world` даёт `166/175 колонок`
      вне мира. Прежний вариант сравнения «две точки стояния друг с другом»
      проходил на общем неверном сдвиге фазы, поэтому в smoke сначала требуется
      world-lock каждого ракурса по отдельности.
- [x] 2.3 Фаза текстуры: `tex_x == 0` на нижней границе тайла, непрерывность
      через соседние тайлы одной стены.
- [x] 2.4 Скользящие лучи (края экрана, сильный наклон) — тоже world-locked:
      именно там перелёт по касательной был максимален.
