# Design

## Причина

DDA идёт по миру шагом `d += 6`. Точка первого попадания берётся из уже
находящегося **внутри** стены шага:

```python
hit_x, hit_y = test_x, test_y          # уже за плоскостью стены
if cur_tx != prev_tx:
    tex_x = int((hit_y - cur_ty * TILE) / TILE * TEX_W) % TEX_W
```

Ошибка по касательной оси = `6 * |компонента направления|`, то есть до 6
мировых единиц = до 6 текселей на проекции вдоль грани. Для скользящих лучей
(край экрана) перелёт по касательной больше, и хвост ошибки в измерениях
доходил до 32 текселей.

## Решение

Плоскость грани, которую луч пересёк, известна точно: это граница между
`prev_tx/prev_ty` и `cur_tx/cur_ty`. Пересечение считается аналитически, и
`tex_x` берётся из него:

- смена `tx` (вертикальная грань): `bx = (prev_tx + 1) * TILE`, если луч идёт
  в `+x`, иначе `bx = cur_tx * TILE`; далее `k = (bx - gs.px) / c` и
  `hit_y = gs.py + s * k`;
- смена `ty` (горизонтальная грань): симметрично, `hit_x = gs.px + c * k`.

Фаза сохраняется: `tex_x` по-прежнему отсчитывается от границы **светлого**
тайла (`cur_tx/cur_ty`), поэтому текстура непрерывна через тайлы и совпадает по
фазе с тем, что было до правки.

## Что специально не меняется

- `d`/`rd`/`z_b`. Расстояние округлено шагом 6 по построению: сдвиг границы
  попадания сдвинул бы границы окклюзии между соседними стенами и изменил бы
  картинку в местах, где этот change ничего не обещал. Текстурная привязка и
  глубина разделены намеренно: вторая задача — свой change.
- Вертикальная привязка текстуры (`idx = r * (TEX_W - 1) // (h - 1)` в
  `_wall_strip`): она уже привязана к верху полосы стены, то есть к мировой
  высоте, и «поворота к игроку» не даёт.

## Границы

`hit_x/hit_y` читаются только для `tex_x` — подтверждено поиском по
`engine/rendering.py` (строки 942-968), поэтому правка не затрагивает
`draw_y`/`wh`/`_z_to_sy`. Деление на компоненту направления безопасно: ветка
`cur_tx != prev_tx` означает пересечение границы по X, значит `cos(ra) != 0`,
и наоборот; оставлена защита на вырожденное значение.

## Проверка

Smoke читает **кадр**, а не формулу: стена получает текстуру-маркер, в которой
тексель кодируется соотношением каналов (`r` против `g`), потому что
затенение множит цвет и соотношение сохраняет. Для каждой точки стены
тексель читается из кадра в двух точках стояния и сравнивается; допуск — 1
тексель (погрешность чтения 8-битным кадром). До правки расхождение
доходило до десятков текселей, после — не превышает допуска.
