## 1. Бинарный контейнер `.mt1` (`map/sector-format`)

- [x] 1.1 Создать `shared/mt1.py`: заголовок (магия `MT1`, версия, число
  срезов, смещение каталога, контрольная сумма), каталог срезов
  (offset/size/name 8b), `pack/unpack` контейнера, строгие коды ошибок.
  Проверка: юнит-скрипт упаковывает/распаковывает контейнер с тестовыми
  срезами и сверяет round-trip; испорченный байт → ошибка каталога/суммы.
- [x] 1.2 Срезы исходной геометрии в `shared/mt1.py`: `VERTEXES`
  (f32 x,y), `LINEDEFS` (u32 v1,v2, u16 flags/special/tag, u32 front/back),
  `SIDEDEFS` (индексы имён, смещения, u32 sector), `SECTORS` (i16
  floor/ceil, индексы флатов, u16 light/special/tag), `THINGS`, `NAMES`
  (таблица уникальных строк). Проверка: round-trip модели карты через
  срезы без потерь значений (точные сравнения атрибутов).
- [x] 1.3 Перевести `SectorMap.to_bytes/from_bytes/load/save` на `.mt1`:
  `from_json` остаётся как импорт старых карт (`"format":"sector"`), файлы
  секторных карт пишутся с расширением `.mt1`; `to_json` оставить для
  отладки/редактора-экспорта. Проверка: `map1.json` импортируется и
  сохраняется читаемым `.mt1`; round-trip байтов карты идентичен модели.
- [x] 1.4 Валидация контейнера: границы каталога, контрольная сумма,
  версия, лимиты (`MAX_VERTICES` и пр. из `sector_map.py`), целостность
  ссылок, наличие сектора и вещи `player1`, `floor_h <= ceil_h`. Проверка:
  юнит-скрипт прогоняет битые контейнеры (обрезанный файл, ссылка за
  границы среза, неверный NAMES-индекс) и сверяет ожидаемые ошибки.

## 2. BSP-структура и срезы `SEGS/SUBSECTORS/NODES/REJECT`

- [x] 2.1 Срезы BSP в `shared/mt1.py`: `SEGS` (ссылки на вершины и линии,
  смещение u), `SUBSECTORS` (первый сегмент + число), `NODES` (разделитель,
  bbox-ы двух частей, дети), `REJECT` (битовая матрица пар секторов).
  Проверка: round-trip срезов; юнит-сверка числа сегментов подсекции с
  заявленным.
- [x] 2.2 BSP-билдер (stdlib, без numpy) `client/engine/bsp.py`: рекурсивная
  бинарная партиция линий (эвристика разделителя: минимум расщеплений,
  максимум суммы длин сторон), расщепление пересекающихся линий, выпуклые
  подсекции, bbox-ы узлов. Проверка: на тестовых картах (комната, окно,
  ступень, вложенные сектора) каждая исходная граница покрыта сегментами,
  глубина дерева конечна, обход back-to-front даёт корректное перекрытие.
- [x] 2.3 Загрузка BSP: `SectorScene` кэширует дерево; если карта (сеть) без
  BSP-срезов — строит при загрузке один раз; файл `.mt1` использует готовые
  срезы. Проверка: загрузка карты с срезами и без даёт одинаковое дерево
  (консистентные подсекции на тесте).
- [x] 2.4 REJECT для сервера: построение (bbox-пересечения секторов,
  консервативно в сторону «непрозрачного») и использование в
  `SectorMap.has_los_px` как early-out. Проверка: юнит-скрипт: пары секторов
  с REJECT-битом дают `has_los_px=False`, полное пересечение игнорируется;
  семантика существующих сценариев (сквозь двустороннюю границу) не меняется.

## 4. BSP-рендер (`renderer/sector-renderer`)

- [x] 4.1 Обход дерева: по точке зрения на каждый узел — порядок
  «ближнее поддерево → дальнее» (как DOOM, стены ближней стороны рисуются
  первыми и задают клип колонок), лист = подсекция; отсечение поддерева по
  bbox узла (вне фрустума/за камерой). Проверка: юнит-рендер двух комнат —
  ближняя стена рисуется поверх дальней, дальняя не рисуется за ней
  (DDA-аналог); решение о near-first зафиксировано при реализации 4.2
  (совместимо со сценариями клиппинга `sector-renderer`).
- [x] 4.2 Проекция сегментов с клиппингом колонок (`clip_top/clip_bot`
  массивы, как ceilingclip/floorclip DOOM): верхние/нижние полосы кромок по
  перепадам высот, solid-стена закрывает колонку, обновление клипа,
  отбрасывание сегментов, целиком скрытых закрытыми колонками (безопасно в
  near-first: уже отрисованные стены ближе). Проверка: кадры окон и ступеней
  корректны (юнит-рендер на поверхность) — кромки окна/ступени, дальняя
  стена только в проёме, артефактов «размазанного» потолка поверх проёма нет.
- [x] 4.3 Флаты через visplane-спаны: группировка спанов колонок одной
  подсекции, перспективная numpy-растеризация (textured) и сплошная заливка
  по уровню флатов; отсечение за стенами. Проверка: кадр без закраски
  пола/потолка поверх стен; переключение текстура→сплошная по бюджету.
- [x] 4.4 Заменить `render_scene` в `sector_render.py` на BSP-обход; zbuffer
  (`view_buf`) сохраняется для спрайтов/корпусов/частиц; удалить DDA-путь и
  `LineIndex` (если не нужен иначе). Проверка: спрайт за стеной не
  отображается, враг на ступени стоит на своём полу; тайловые карты — без
  изменений (регрессия `smoke_custom_map.py`).
- [x] 4.5 Адаптивный бюджет: BSP-путь живёт в существующем контроллере
  (`render_scale`, `vs_scale`, уровень флатов/спрайтов), один upscale за
  кадр. Проверка: `smoke_performance`-аналог с искусственной нагрузкой;
  на эталонной слабой машине секторная сцена держит 60 FPS.
