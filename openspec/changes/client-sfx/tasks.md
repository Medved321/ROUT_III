## 1. Модуль `client/sfx.py`

- [x] 1.1 `_synth(name)` / генератор: из таблицы-описания (форма волны, свип
      частоты, доля шума, огибающая, длительность) собирает `bytes` в формате
      микшера и оборачивает в `pygame.mixer.Sound(buffer=...)`. Проверка:
      `smoke_sfx.py` на подменённом `get_init()` строит банк и убеждается, что
      длина буфера совпадает с частотой/каналами (44.1k стерео и 22.05k моно)
- [x] 1.2 `_ensure_bank()`: строит банк один раз, кэширует `Sound` по имени;
      если микшер не готов — банк пуст, без исключений. Проверка: тест без
      микшера видит пустой банк и `play()` не падает
- [x] 1.3 `play(name, cooldown=None)`: минимальный интервал повтора на звук и
      ограничение одновременных каналов (`pygame.mixer.set_num_channels` /
      `find_channel`); неизвестное имя и сбой — молча. Проверка: тест гоняет
      серию вызовов за один кадр и видит не больше одного проигрывания на
      кулдаун, клиент не падает
- [x] 1.4 `set_volume(v)`: клампит 0..1 и применяет ко всем созданным `Sound`;
      0 — тишина без ошибок. Проверка: тест видит применённую громкость на
      нескольких звуках и зажим `2 → 1`, `-1 → 0`
- [x] 1.5 Банк звуков для событий: `shoot` (разный тембр на классы оружия),
      `hit_wall`, `hit_enemy`, `pickup`, `hurt`, `death`, `door`, `dash`.
      Проверка: тест перечисляет имена и убеждается, что каждое есть в банке
