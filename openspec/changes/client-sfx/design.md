## Context

- Звук в клиенте теперь принадлежит `client/music.py`: он **единственный**, кто
  поднимает микшер (`pygame.mixer.init`, фиксированные параметры + запасная
  попытка), и он же — единственный владелец `pygame.mixer.music`. Запуск —
  `music.start(...)` в `GameClient.run()`; громкость музыки применяется из
  `client/settings.py::_apply_audio()`.
- `client/settings.py` уже содержит `sfx_vol` (строка настроек «Громкость
  звука»), но её никто не читает — это надо закрыть.
- Событий в клиенте достаточно, чтобы озвучить игру без сервера:
  - выстрел — врата темпа открываются в `client/client.py:996-1018` (там уже
    предсказывается отдача), оружие известно (`fired_wpn`);
  - попадания — `self.impacts` из снимка (`client.py:1046`), у каждого есть `id`
    для дедупликации (это уже делает `client/bridge.py:408-422`);
  - предметы/двери — `self.items`, `self.doors` из снимка (`client.py:1050-1053`);
  - урон/смерть/дэш — `local_health`, `local_state` из последнего снимка
    (`client.py:1064-1072`).
- Ассетного пайплайна нет: `tools/build_client.py` кладёт в zipapp только
  пакеты, а бинарные файлы неудобно ревьюить. Поэтому звук синтезируется.
- `music-playback` вводит в `client/music.py` возможность узнать/поднять
  микшер; SFX переиспользует это, а не заводит второй владелец.

## Goals / Non-Goals

**Goals:**

- Озвучить ключевые игровые события из состояния клиента и снимка, без
  протокола и сервера.
- Один владелец SFX-воспроизведения (`client/sfx.py`), разделяющий микшер с
  музыкой; ноль новых файлов ассетов; ноль зависимостей кроме stdlib + pygame.
- Работать на любом железе: нет микшера/устройства/сбоя синтеза → тишина, игра
  не падает; спам событий ограничен.
- Громкость «Громкость звука» работает и меняется на ходу.

**Non-Goals:**

- Звуки в меню/лобби/редакторе (клики кнопок и т.п.) — отдельная задача.
- Позиционное 3D-затухание (панорама/громкость по расстоянию).
- Изменения в `engine/`, `server/`, `shared/`, формате карт, zipapp-сборке.
- Музыка — уже закрыта `music-playback`, здесь не трогается.

## Decisions

1. **Процедурный синтез вместо файлов ассетов.**
   Банк строится в памяти на старте: генератор собирает `bytes` в формате
   микшера и оборачивает в `pygame.mixer.Sound(buffer=...)`. Только `array`/
   `math`/`struct` из stdlib. Тон/шум + огибающая + свип частоты дают Doom-подобный
   «бип/щелчок» без файлов.
   *Альтернатива:* положить WAV в `assets/` — отвергнуто: бинарь в ревью + не
   попадает в zipapp (как музыка) + лицензии на чужие сэмплы.

2. **Формат синтеза берётся у микшера, а не объявляется.**
   `pygame.mixer.get_init()` возвращает `(freq, size, channels)`; генератор
   строит буфер ровно под них. Иначе `Sound(buffer=...)` отвергнет буфер на
   запасном профиле `22050`/mono.

3. **`client/sfx.py` — второй владелец только *проигрывания*, не микшера.**
   Модуль зовёт готовый микшер музыки (публичная проверка готовности в
   `client/music.py`), инициализацию не повторяет. Если микшер не поднялся —
   весь модуль молча тихий.

4. **Триггеры — в клиенте, по событию, а не покадрово.**
   - огонь: в момент открытия врат (там же, где стартует предсказанная отдача) —
     отзывчиво; тухлый выстрел (сервер откажет) даст звук, как и отдача, это
     ожидаемо и совпадает с уже принятым поведением рендера;
   - попадание: новый `id` в `self.impacts` (дедуп по id, как в `bridge.py`), тип
     `enemy`/`wall` задаёт звук;
   - подбор: `id` предмета исчез из `self.items`, пока игрок рядом;
   - урон/смерть: падение `local_health` и переход `local_state` в «мёртв»;
   - дверь: новый открытый linedef в `self.doors`.
   *Альтернатива:* звук строго по подтверждённому `fire_seq` — отвергнуто:
   звук отставал бы на круг снимка и читался как «залипание».

5. **Ограничители спама.**
   У каждого звука — минимальный интервал повторного запуска; число
   одновременных каналов микшера конечно. Частые события (серия попаданий)
   схлопываются, чтобы не выесть каналы и не трещать.

6. **Громкость — один set-owner.**
   `client/sfx.py::set_volume(v)` клампит 0..1 и применяет ко всем уже созданным
   `Sound`. `settings.py::_apply_audio()` передаёт и `music_vol`, и `sfx_vol`.

7. **Сбой = тишина.**
   Инициализация и каждый `play()` — под `try/except`; исключение звука никогда
   не доходит до игрового цикла, как и у музыки.

## Risks / Trade-offs

- **Стоимость старта.** Синтез банка — десятки мс на старте партии. Митигация:
  маленькие буферы (десятки–сотни мс), генерация один раз, кэш `Sound`; при
  медленном синтезе банк можно строить лениво при первом событии.
- **Предсказанный звук выстрела на отказе.** Оружие без патронов «щёлкнет».
  Принято сознательно ради отзывчивости; при необходимости добавить отдельный
  звук «пусто» по `fire_reason` из снимка.
- **Перегрузка каналов.** Митигация из решения 5; `Sound` кэшируется, а не
  пересоздаётся на каждый выстрел.
- **Разные оружия должны звучать по-разному.** Скорее вкусовое; параметры
  подбираются при реализации, поведение спецификации не меняет.
