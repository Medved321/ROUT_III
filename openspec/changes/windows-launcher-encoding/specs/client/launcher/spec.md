## Purpose

Гарантирует, что Windows-лаунчеры (`run_client.bat`, `run_server.bat`)
запускаются двойным кликом и из консоли без искажений: cmd.exe разбирает их
однозначно, выбирается нужный интерпретатор, аргументы доходят целиком, а
сообщения об ошибках читаемы.

## ADDED Requirements

### Requirement: Детерминированный разбор batch-файлов

Файлы `run_client.bat` и `run_server.bat` SHALL содержать только ASCII-байты
(0x00–0x7F) и SHALL использовать CRLF-переводы строк. Разбор команд SHALL NOT
зависеть от активной кодовой страницы консоли или `chcp`.

#### Scenario: Запуск двойным кликом

- **WHEN** пользователь запускает `run_client.bat` двойным кликом
- **THEN** все строки выполняются целиком, без сообщений вида
  `'... is not recognized` и без запуска частей строк как команд

#### Scenario: Кириллица не встречается в batch

- **WHEN** файл `.bat` прочитан побайтово
- **THEN** в нём нет байтов ≥ 0x80, а строки разделены CRLF, не одиночным LF

### Requirement: Выбор интерпретатора и проброс аргументов

Лаунчер SHALL пробовать интерпретаторы в порядке `py -3.12`, затем `py -3`,
затем `py`, затем `python`; при успехе запуск продолжается, при неудаче —
переходит к следующему кандидату. Аргументы командной строки (`%*`) SHALL
передаваться целевой программе без потери и искажения.

#### Scenario: Есть только нужный Python

- **WHEN** интерпретатор по умолчанию — Python 3.14, а также установлен
  Python 3.12
- **THEN** лаунчер выбирает 3.12 и запускает через bootstrap, а не 3.14

#### Scenario: Аргументы доходят целиком

- **WHEN** пользователь запускает `run_client.bat --name Test`
- **THEN** `--name Test` доходит до `tools/launch_client.py` без изменения

### Requirement: Читаемые сообщения об ошибке

При отсутствии подходящего Python лаунчер SHALL вывести понятное ASCII-
сообщение и приостановиться для прочтения; сообщения SHALL NOT превращаться в
mojibake и SHALL NOT ломать разбор последующих строк.

#### Scenario: Python не найден

- **WHEN** ни один из кандидатов интерпретатора недоступен
- **THEN** выводится понятное ASCII-сообщение с подсказкой установить
  Python 3.12+, и окно ожидает нажатия клавиши
