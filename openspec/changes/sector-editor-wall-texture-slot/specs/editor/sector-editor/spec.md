# Spec Delta

## ADDED Requirements

### Requirement: Основная текстура стены (mid) доступна из палитры

Палитра текстур стен редактора секторов SHALL позволять назначить основную
текстуру стены (`mid`), а не только губы ступеней (`lower`/`upper`): чип слота
`mid` SHALL быть в одном ряду с чипами стороны (`ПЕРЕД`/`ЗАД`) и губ, а ширина
чипа SHALL вычисляться из числа чипов так, чтобы каждый чип целиком лежал в
панели и его нарисованный прямоугольник совпадал с зоной клика.

Когда выделена линия, цель палитры по умолчанию SHALL совпадать с поверхностью,
которую рендер рисует для этой линии: `mid` — для сплошной стены, `lower` — для
двустороннего порта (проёма). Клик по имени в сетке SHALL записывать текстуру в
выбранный слот выбранной стороны; слот `mid` пишется в `SideDef.mid`.

#### Scenario: сплошная стена по умолчанию целится в основную текстуру

- **WHEN** автор выделяет сплошную стену и кликает по имени текстуры в палитре
- **THEN** цель палитры — `mid`, клик записывает имя в `SideDef.mid`, и стена
  рисуется с этой текстурой

#### Scenario: проём по умолчанию целится в губу ступени

- **WHEN** автор выделяет двусторонний проём и кликает по имени текстуры
- **THEN** цель палитры — `lower`, клик записывает имя в `SideDef.lower`, как и
  раньше

#### Scenario: чип основной текстуры помещается в панель

- **WHEN** палитра стен построена
- **THEN** чип `mid` нарисован, целиком лежит внутри панели, и его hit-бокс равен
  нарисованному прямоугольнику
