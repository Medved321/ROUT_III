## Purpose

Позволяет клиенту получать новую версию с сервера, проверять её и применять с перезапуском, не переустанавливая игру вручную.

## ADDED Requirements

### Requirement: Update offer

При устаревшей версии клиента сервер MUST предложить обновление, указав доступную версию, размер и контрольную сумму.

#### Scenario: Доступно обновление

- **WHEN** подключившийся клиент устарел
- **THEN** сервер сообщает версию, размер и контрольную сумму новой версии

### Requirement: Download and verify

Клиент MUST скачать предлагаемую версию по надёжному каналу и MUST проверить её контрольную сумму до применения.

#### Scenario: Успешная загрузка

- **WHEN** клиент получает предложение об обновлении и принимает его
- **THEN** он скачивает файл по надёжному каналу
- **AND** применяет его только после успешной проверки контрольной суммы

### Requirement: Explicit confirmation

По умолчанию клиент MUST запрашивать у пользователя подтверждение перед применением обновления; при отказе клиент MUST NOT применять файл.

#### Scenario: Пользователь отказывается

- **WHEN** пользователю предложено обновление и он отказывается
- **THEN** текущая версия клиента продолжает работать без изменений

#### Scenario: Пользователь соглашается

- **WHEN** пользователь подтверждает обновление
- **THEN** новая версия применяется и клиент перезапускается на ней

### Requirement: Atomic apply

Клиент MUST NOT перезаписывать файл, с которого запущен; новую версию SHALL сохранять отдельным артефактом, а запуск SHALL переключать на неё.

#### Scenario: Применение без перезаписи

- **WHEN** обновление применено
- **THEN** новая версия сохранена отдельным файлом
- **AND** работающий файл остаётся неизменным до перезапуска

### Requirement: Safe failure

При обрыве передачи или несовпадении контрольной суммы клиент MUST NOT применять файл и MUST сохранять работоспособность текущей версии.

#### Scenario: Обрыв передачи

- **WHEN** передача прерывается до завершения
- **THEN** частично загруженные данные не применяются
- **AND** текущая версия продолжает работать

### Requirement: Code updates without content transfer

Обновление SHALL заменять только код клиента и MUST NOT требовать повторной передачи ассетов, хранящихся отдельно.

#### Scenario: Ассеты не пересылаются

- **WHEN** выходит новая версия кода
- **THEN** обновляется только код
- **AND** ассеты остаются на диске и не передаются по сети
