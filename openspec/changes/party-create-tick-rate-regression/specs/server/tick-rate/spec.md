# Spec Delta

## Purpose

Согласованность частоты тиков и версии протокола обязательна не только для
таймингов внутри матча, но и для самого входа в него: создание партии должно
использовать ту же частоту, которая объявлена в `HELLO_ACK`, и ту версию
протокола, которая её содержит.

## ADDED Requirements

### Requirement: Создание партии использует согласованную частоту тиков

Сервер SHALL создавать игровой мир партии с той частотой тиков, которую он
получил при запуске и объявил клиенту. `GameWorld` SHALL принимать `tick_rate`
как аргумент конструктора и SHALL выводить из него все свои тик-деноминированные
тайминги. Сервер SHALL NOT создавать мир с fixture-частотой по умолчанию, если
запущен с другой частотой.

#### Scenario: Партия на частоте, отличной от значения по умолчанию

- **WHEN** сервер запущен с `--fps 40` и клиент отправляет `CREATE_PARTY`
- **THEN** создаётся партия, её `world.tick_rate` равен 40, а клиент получает
  подтверждение входа в партию

#### Scenario: Кнопка создания в лобби

- **WHEN** игрок нажимает видимую кнопку «Создать» в лобби
- **THEN** сервер получает `CREATE_PARTY`, создаёт партию и отвечает
  `JOIN_ACCEPT`; кнопка не может «ничего не делать» из-за исключения в
  обработчике

#### Scenario: Исключение обработчика не проглатывается молча

- **WHEN** обработчик `CREATE_PARTY` падает до ответа клиенту
- **THEN** это считается нарушением контракта и ловится регрессией; сервер
  SHALL отвечать клиенту результатом операции, а не оставлять его в лобби без
  ошибки

### Requirement: Версия протокола соответствует полю частоты тиков

Пока `HELLO_ACK` содержит поле `tick_rate`, `PROTOCOL_VERSION` SHALL равняться
16. Сервер и клиент SHALL использовать одно и то же значение; несовпадение
версий SHALL отвергаться по уже существующему механизму проверки.

#### Scenario: Подключение с правильной версией

- **WHEN** клиент с `PROTOCOL_VERSION = 16` подключается к серверу
- **THEN** `HELLO_ACK` принимается, частота тиков читается из поля и используется
  соединением

#### Scenario: Подключение с устаревшей версией

- **WHEN** клиент с `PROTOCOL_VERSION = 15` подключается к серверу версии 16
- **THEN** сервер отвергает его как несовместимого и не допускает до партий
