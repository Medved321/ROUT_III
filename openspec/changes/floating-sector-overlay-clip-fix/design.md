# Design

## Причина дефекта 1: стык плита↔плита

`SectorScene._line_borders_slab()` и `bsp._floating_lines()` помечали только
границы «парящий ↔ непарящий». Общая линия двух плит оставалась обычной
двусторонней линией. В `_seg_wall_bands()` для неё `Sf = Bf = floor_h`,
`Sc = Bc = ceil_h`, а у плиты `floor_h > ceil_h`, поэтому условие
`Bf >= Sc or Bc <= Sf` истинно и `two = False`: линия уходит в ветку сплошной
стены. Полоса не появляется (`yf < yc`), но `solid_depth[col]` и
`view_buf[col]` получают расстояние до стыка. Оверлей обрезает интервал луча
по `view_buf`, поэтому дальняя плита теряет всю часть за стыком.

Решение: границей оверлея считается **любая** линия, у которой есть парящая
сторона. Такой сег не становится секущей плоскостью и не попадает в
`_seg_wall_bands()`. Визуализация стыка целиком живёт в
`platform_render._side_bands()`: равные высоты дают пустоту (невидимый
внутренний шов), разные — вертикальную грань-ступень.

## Причина дефекта 2: клипы от дальнего сектора

`clip_top`/`clip_bot` — это frontier **самого дальнего** видимого проёма в
колонке. Оверлей рисовался после базового прохода и применял их как свои
границы. Когда за плитой находится другой сектор, его портал зажимает
интервал, хотя он дальше плиты; плита отсекается целиком. Хранить только
расстояние последнего портала недостаточно: если плита стоит между двумя
дверными проёмами, дальний портал затирает глубину ближнего и ближний проём
перестаёт ограничивать плиту.

Решение: базовый проход хранит `clip_hist[col]` — список снимков
`(depth, top, bot)` после каждого портала, зажавшего клип колонки. Обход идёт
от ближнего к дальнему, поэтому список упорядочен по `depth`. Для плиты с
ближним краем `t0` оверлей берёт последний снимок с `depth <= t0`; если его
нет, интервал колонки полный `[0, ih]`. Тест depth по `view_buf` не меняется:
ближняя сплошная стена по-прежнему запрещает рисовать плиту.

Свойства:

- плита перед всеми порталами: снимков впереди нет → полный интервал → плита
  видна;
- плита за ближним дверным проёмом: последний снимок перед ней — этот проём →
  плита видна только в нём;
- плита между двумя проёмами: берётся снимок ближнего, дальний игнорируется;
- карты без плит: `clip_hist` не выделяется вовсе, кадр не меняется.

## Стоимость

Один список из `iw` указателей только на картах с плитами, по небольшому
снимку на каждый портал, зажавший клип, и один проход по истории с конца на
интервал плиты. Новых поверхностей нет.
