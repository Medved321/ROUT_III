## Purpose

Уточняет поведение существующего автообновления: подтверждение учитывает
сохранённый отказ игрока, чтобы предложение не повторялось для той же версии.

## MODIFIED Requirements

### Requirement: Explicit confirmation

По умолчанию клиент MUST запрашивать у пользователя подтверждение перед
применением обновления; при отказе клиент MUST NOT применять файл и MUST
запомнить отклонённую версию, чтобы не предлагать её повторно при следующих
подключениях. Предложение версии, строго более новой, чем сохранённая
отклонённая, MUST снова запрашивать подтверждение.

#### Scenario: Пользователь отказывается

- **WHEN** пользователю предложено обновление и он отказывается
- **THEN** текущая версия клиента продолжает работать без изменений
- **AND** версия предложения сохраняется и не предлагается повторно

#### Scenario: Пользователь соглашается

- **WHEN** пользователь подтверждает обновление
- **THEN** новая версия применяется и клиент перезапускается на ней

#### Scenario: Вышла более новая версия

- **WHEN** после отказа опубликована строго более новая версия
- **THEN** подтверждение запрашивается снова
