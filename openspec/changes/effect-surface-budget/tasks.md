## 3. Поверхности эффектов

- [x] 3.1 `engine/particles.py`: `_circle_radius(r)` — ближайшая ступень
      лестницы с шагом `CIRCLE_RADIUS_STEP`, зажатая сверху `CIRCLE_MAX_R`;
      лестница строится один раз при импорте. Проверка: сценарий 6
      (`smoke_effect_surfaces.py`): для радиусов 1..4999 приведённый радиус
      всегда является ступенью лестницы, не превышает предел и отличается от
      исходного не больше чем на половину ступени.
- [x] 3.2 `engine/particles.py`: `_cached_circle_surface()` — перед выделением
      радиус приводится к лестнице, а суммарная площадь кэша (считается по
      записям, без отдельного счётчика) сверяется с `CIRCLE_CACHE_PX` и с
      `_SURFACE_CACHE_MAX`; при нехватке места кэш очищается целиком.
      Проверка: сценарий 6 (бюджет не превышается на 5000 разных радиусах, а
      «установившаяся» сцена не аллоцирует каждый кадр).
- [x] 3.3 `engine/particles.py`: общий `_draw_soft_circle(cache, cx, cy, r,
      col, alpha)` — при `r > CIRCLE_MAX_R` рисует примитивом с альфой в
      цвете, иначе кэшированную поверхность (центрируя по её радиусу, а не по
      `r`). `draw_particles()` (дым) и `draw_decals()` (копоть) зовут только
      его. Проверка: сценарий 4 `smoke_effect_surfaces.py` (крупный дым: экран
      изменён, ни одной новой поверхности) — «изменён» проверяется по
      перехвату `pygame.draw.circle`, а не по пикселям кадра: на двух единицах
      линия пола тайловой проекции уходит далеко под экран, и сравнение пикселей
      прошло бы и для пропущенного эффекта.
- [x] 3.4 `engine/rendering.py`: `_ghost_sprite()` и `_blank_sprite()`
      зажимают размер сверху `FALLBACK_SPRITE_MAX`. Проверка: сценарий 7
