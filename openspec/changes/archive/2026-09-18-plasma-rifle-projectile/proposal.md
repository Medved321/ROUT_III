## Why

BFG/RIFLE-«плазма» сейчас стреляет мгновенным hitscan — не видно ни трассы,
ни шара, ни момента попадания. Игрок ждёт «следов от выстрелов» и видимого
проджектайла, как в ROUT_II_III, где часть пушек летела пулями со спрайтом.
При этом рендер уже умеет рисовать светящиеся шары (`from_player`), а сервер —
шагать серверные снаряды врагов; нужно только провести шар игрока по тому же
каналу и добавить визуальные следы от выстрелов.

## What Changes

- Добавить серверный снаряд «плазма-шар» для RIFLE (пушка считается
  «плазма-пушкой»): выстрел становится не мгновенным hitscan, а проектil'ем,
  летящим по направлению взгляда.
  - Сервер шагает шар по тику (уже есть `_update_bullets` для пуль врагов);
    урон — по долёту (попадание во врага или игрока PvP), а не мгновенно.
  - Шар летит в снапшот `WORLD_STATE` тем же списком `bullets` + флаг
    `from_player`, чтобы клиент рисовал светящийся orb (ветка уже есть в
    рендере — 3 концентрических круга).
- Добавить «следы от выстрелов» для хитскан-пушек:
  - локальные частицы при выстреле (вспышка/искры у дула) и в точке попадания
    (искры/дым), через готовый `client/engine/particles.py`
    (`spawn_particles`, `spawn_sparks`, `spawn_smoke_trail`);
  - точка попадания хитскан-луча приходит с сервера (impact-событие), чтобы
    след был в честном месте, а не по локальной прикидке клиента.
- Скоростная сохранность:
  - у шара нет `rotozoom` на кадр (рисование кругами — дёшево);
  - лимиты на число активных шаров и impact-частиц на сервере и клиенте;
  - impact-события — короткоживущие, капаются.

**Опять не трогаем**: рекомендованную в explore-режиме схему «шар серверный,
урон по долёту» — без изменения дизайна на чисто-косметический шар.

## Impact

- `server/game_data.py` — константы для шара (спид, max_dist, лимит),
  `WPN[RIFLE]` → `proj: True`.
- `server/weapons.py` — `handle_shoot`: RIFLE спавнит шар вместо hitscan;
  остальные пушки остаются hitscan + пишут impact-событие.
- `server/game_world.py` — шаг шаров игрока (по аналогии с `_update_bullets`),
  damage по долёту, impact-события в снапшоте, лимиты.
- `shared/protocol.py` — `bullets` в `WORLD_STATE`: добавить флаг
  `from_player` (структура `!ffBBBB` / `!ffBBB`+flag); impact-события
  (`!H count` + `!ffB type`). **BREAKING** для существующего wire-формата.
- `client/client.py`, `client/engine/bridge.py` — передача новых полей,
  заполнение `gs.bul`/`gs.proj` с `from_player`, impact-частицы.
- `client/engine/rendering.py` — уже умеет `from_player` orb; правки только
  если нужно (цвет/размер шара RIFLE).
- `client/engine/particles.py` — переиспользуем без изменений (или мелкая
  функция «impact след»).
- Тесты: `smoke_*` для протокола/сервера, headless-рендер кадра с шаром.
