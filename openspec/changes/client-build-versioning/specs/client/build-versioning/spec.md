## Purpose

Обеспечивает согласованность версионирования клиентских артефактов: версия,
которую клиент сообщает серверу при подключении, совпадает с версией релиза,
под которой он собран и опубликован, чтобы апдейтер сходился и не предлагал
повторные обновления самого себя.

## ADDED Requirements

### Requirement: Артефакт сообщает версию релиза
Каждый собранный клиентский артефакт SHALL сообщать при HELLO `CLIENT_VERSION`,
равный версии релиза, под которой он опубликован (`--version`), сохраняя
`PROTOCOL_VERSION` из исходников.

#### Scenario: Сборка отчитывается своей версией
- **WHEN** артефакт собран с `--version 1.0.2`
- **THEN** артефакт содержит `CLIENT_VERSION` = `"1.0.2"` и `PROTOCOL_VERSION`
  из текущих исходников

### Requirement: Апдейтер сходится после установки релиза
Когда клиент уже работает на версии, равной последней опубликованной, сервер
SHALL NOT предлагать ему обновление.

#### Scenario: Актуальный клиент не получает предложения обновиться
- **WHEN** клиент с `CLIENT_VERSION "1.0.2"` подключается к серверу, у которого
  `latest()` = `1.0.2`
- **THEN** сервер не сообщает `has_update`, и клиент не показывает диалог
  обновления и не повторяет скачивание

#### Scenario: Старый клиент по-прежнему получает предложение
- **WHEN** клиент с `CLIENT_VERSION "1.0.0"` подключается к серверу, у которого
  `latest()` = `1.0.2`
- **THEN** сервер сообщает `has_update`, клиент скачивает `1.0.2` и после
  перезапуска больше не получает предложение
