  D2/D3/D5). Используются русские ключевые слова

  `пол/потолок/свет/пол_текстура/потол_текстура/стена/текстура/
  текстура_верх/текстура_низ/тег/триггер`). Проверка: пример карты

  `two_sided=True` и обе стороны ссылаются на свои секторы.

  light/special/tag и вещам.

## 2. Текстуры, свет, механики и вещи

- [x] 2.1 Текстуры: `пол_текстура`/`потол_текстура` -> `floor_tex`/`ceil_tex`;
  `стена`/`текстура` -> mid; `текстура_верх`/`текстура_низ` -> upper/lower.
  Список имён сверяется с `engine/textures.py`. Проверка: комната с
  `lava`/`ceiling`/`wall` сериализуется в `.mt1` и читается обратно с теми
  же именами.
- [x] 2.2 Свет: `свет N` валидируется 0..255 с понятной ошибкой вне
  диапазона. Проверка: `свет 300` -> error «строка N: свет вне 0..255».
- [x] 2.3 Механики-данные: `тег N` на комнате -> `Sector.tag`; `тег N`/
  `триггер тип ТЕГ` на `СТЕНА` -> `LineDef.special/tag` через таблицу
  типов («рычаг», «дверь» и т.п.). Проверка: round-trip special/tag через
  `.mt1` без потерь; поведение не реализуется (резерв).
- [x] 2.4 Вещи: `ИГРОК` -> `player1`; `ВРАГ <имя>` -> `ENEMY_NAMES`;
  `АПТЕЧКА`/`ПАТРОНЫ` -> `med`/`amm`. Проверка: `spawn_px()` возвращает
  `ИГРОК`-позицию; вещи врагов/предметов сохраняются в `things`.

## 3. Ошибки и краевые случаи

- [x] 3.1 Понятные ошибки с номерами строк: не-разрешённая команда,
  комната без «угол»/без сектора, разомкнутый контур, дубликат координат.
  Проверка: `smoke_text_map.py` проверяет каждое сообщение на русском и
  номер строки. Парсер работает на UTF-8 без BOM.
