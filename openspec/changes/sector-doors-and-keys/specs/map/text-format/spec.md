# Spec Delta

## MODIFIED Requirements

### Requirement: Ключевые слова и структура файла

Формат SHALL быть текстовым файлом `.mts` с построчными командами на
русском языке: `КОМНАТА`, `угол`, `СТЕНА`, `ИГРОК`, `ВРАГ`, `АПТЕЧКА`,
`ПАТРОНЫ`, `ДВЕРЬ`, `КЛЮЧ`, параметры `пол`, `потолок`, `свет`, `пол_текстура`,
`потол_текстура`, `стена`, `текстура`, `текстура_верх`, `текстура_низ`,
`тег`, `триггер`, `замок`, признак `сплошная`, и комментарии `#`. Команды
`КОМНАТА`/`СТЕНА`/`ДВЕРЬ`/`ИГРОК`/`ВРАГ`/`АПТЕЧКА`/`ПАТРОНЫ`/`КЛЮЧ` могут идти
в любом порядке, параметры относятся к последней сущности. Признак `сплошная`
SHALL применяться к общей грани двух комнат и SHALL превращать её из проёма в
глухую стену; при сериализации обратно он SHALL сохраняться.

Команда `ДВЕРЬ x1 y1 x2 y2 [цвет]` SHALL описывать явную дверную грань
(двусторонний лайндеф со спецэффектом двери), где необязательный `цвет` задаёт
замок: `нет` (по умолчанию), `красный`, `жёлтый` или `синий`. Параметр
`замок <цвет>` (в комнате или на `СТЕНА`/`ДВЕРЬ`) SHALL задавать тот же замок.
Команда `КЛЮЧ x y цвет` SHALL размещать вещь-ключ `key_red`/`key_yellow`/
`key_blue` по цвету. При обратной сериализации двери, замки и ключи SHALL
восстанавливаться.

#### Scenario: Простая комната

- **WHEN** файл содержит `КОМНАТА Зал`, `пол 0`, `потолок 128`, `свет 160`
  и четыре строки `угол x y`
- **THEN** парсер строит сектор `Зал` с заданными высотами/светом и
  замкнутый контур из четырёх вершин и четырёх односторонних линий

#### Scenario: Соседние комнаты на разных уровнях

- **WHEN** файл задаёт две комнаты с общей гранью и разными значениями `пол`
- **THEN** общая грань становится двусторонней ступенью, а высоты пола комнат
  сохраняются раздельно

#### Scenario: Глухая стена между комнатами

- **WHEN** в описании общей грани двух комнат указана строка `сплошная`
- **THEN** парсер помечает эту двустороннюю линию как сплошную стену, и при
  обратной сериализации строка `сплошная` восстанавливается

#### Scenario: Дверь без замка

- **WHEN** файл содержит `ДВЕРЬ 64 0 64 64` (без цвета)
- **THEN** парсер строит двустороннюю дверь с mid-текстурой `door_D` на обеих
  сторонах

#### Scenario: Запертая дверь

- **WHEN** файл содержит `ДВЕРЬ 64 0 64 64 жёлтый`
- **THEN** парсер строит дверь с mid-текстурой `door_Y` и при обратной
  сериализации восстанавливает цвет замка

#### Scenario: Ключ на карте

- **WHEN** файл содержит `КЛЮЧ 96 32 синий`
- **THEN** парсер размещает вещь `key_blue`, и при обратной сериализации строка
  `КЛЮЧ` с тем же цветом восстанавливается
