# Design

## Корень

`_seg_wall_bands()` (двусторонняя ветка, `clip_top`/`clip_bot` не `None`)
рисует две грани двусторонней линии — верхнюю и нижнюю. Нижняя построена так:

```python
yl = yc if yc > ceilt else ceilt
yh = yf if yf < flrob else flrob
...
# Lower lip: back floor ABOVE the front floor on screen.
if yfb < yf:
    r0 = yfb if yfb > yl else yl
    if yh > r0:
        bands.append((col, r0, yh, low_tex, lv, tu, ...))
    clip_bot[col] = r0 if r0 > yfb else yfb
else:
    clip_bot[col] = yh
```

Здесь `yf` — линия пола переднего сектора на глубине `t`, `yfb` — линия пола
заднего. Экранная координата строки для высоты `z`:

```
y = hc + (eye - z) * F / t
```

Поэтому `yfb < yf` ⇔ `Bf > Sf` ⇔ задний пол **выше**. Ветка покрывает только
ступень вверх.

Для ямы `Bf < Sf`, значит `yfb > yf`, и выполняется `else`. Дальше:

1. Полоса грани не добавляется в `bands` — на экране нет ничего, что обозначало
   бы обрыв.
2. `clip_bot[col] = yh = min(yf, flrob)` прибивается к линии пола **комнаты**.
   Спан пола ямы, который её собственные сеги пушат позже по обходу
   near→far, имеет вид `[max(ceilt, yf_ямы), clip_bot]`, а `yf_ямы > yf_комнаты
   = yh`. Значит `y1 <= y0`, и `_push_flat()` его отбрасывает.

Два следствия складываются в «дыры не видно»: пол комнаты непрерывно
закрашивает пропасть (флаты рисуются в фазе B, а грани в фазе C затирают их
только там, где построены), а дно ямы не рисуется вовсе.

## Решение

Грань — это вертикальная поверхность между двумя линиями пола, и её полоса не
зависит от того, выше задний пол или ниже. Единственное, что различается, —
какой конец полосы ближе к горизонту:

```
yfb < yf  (ступень вверх)   полоса [yfb, yf]
yfb > yf  (яма)             полоса [yf, yfb]
```

Поэтому направление не проверяется вовсе, а границы берутся как
`[min(yf, yfb), max(yf, yfb)]`, обрезанные открытым интервалом колонки
`[yl, flrob]`. `clip_bot` после этого — `max(yfb, yl)`: у ямы это линия пола
ямы (она ниже `yf`, а `yf >= yl`, потому что `floor_h <= ceil_h`), у ступени
вверх — как раньше.

```python
lo = yfb if yfb < yf else yf
hi = yfb if yfb > yf else yf
if lo < yl:
    lo = yl
if hi > flrob:
    hi = flrob
if hi > lo:
    bands.append((col, lo, hi, low_tex, lv, tu,
                  ax1, ay1, ax2, ay2, t))
clip_bot[col] = yfb if yfb > yl else yl
```

### Тождество для ступени вверх

При `yfb < yf`: `lo = max(min(yf,yfb), yl) = max(yfb, yl) = r0` и
`hi = min(max(yf,yfb), flrob) = min(yf, flrob) = yh` — ровно прежние границы.
`clip_bot = max(yfb, yl) = r0 if r0 > yfb else yfb` — тоже как прежде
(`max(max(yfb,yl), yfb) = max(yfb, yl)`). Значит кадр на ступенях вверх
меняется побайтово ноль, а не «на глаз похоже».

### Почему полосу достаточно, пол не нужно перерисовывать

Пол комнаты пушится как `[max(ceilt, yf), flrob]` — до обновления клипа, то
есть уже покрывает и строки ямы. Ничего отменять не нужно: стены рисуются в
фазе C **после** флатов (фаза B) и затирают пол ровно на своей полосе. Грань —
обычная полоса в `bands`, поэтому порядок фаз работает на неё тем же путём,
что и на ступень вверх.

## Альтернативы

- **Отрисовать яму отдельной сущностью/эффектом.** Отвергнуто: дыра — это
  обычная двусторонняя линия в существующей модели, новый примитив и новая
  настройка качества не нужны, а `lower` уже назначается редактором.
- **Поменять знак сравнения на `yfb != yf`, оставив две ветки.** Отвергнуто:
  две почти одинаковые ветки расходятся при `yh`-обрезке и это уже источник
  бага; одна формула симметрична и доказанно тождественна старой на ступени
  вверх.
- **Схлопнуть `Bc <= Sf` в «дыру».** Отвергнуто: это не дыра, а порода между
  секторами; DOOM рисует там сплошную стену, и врать здесь — значит показать
  игроку несуществующий проём.
- **Трогать верхнюю грань заодно.** Отвергнуто: та же асимметрия, но к жалобе
  не относится и ломает работающие случаи «потолок ниже»; вынесено в
  non-goals.

## Проверка

`smoke_sector_pits.py` рендерит «комната + провал» в трёх конфигурациях
(глубина 64 / ступень 16 / контроль без перепада) и требует:

- **дно ямы видно**: спанов пола ямы > 0 и на кадре есть пиксели её текстуры;
- **глубина видна**: кадр для −64 отличается от кадра для −16 (раньше был
  тождественно равен);
- **грань на месте**: полоса `lower` присутствует и лежит между линиями полов;
- **`z_b` узнаёт о яме**: ближний край обновляет `clip_bot`, дно видно;
- **ступень вверх не сломана**: контрольный кадр совпадает с эталоном.

Невакуумность проверяется временным возвратом `else`-ветки: тесты обязаны
падать.
