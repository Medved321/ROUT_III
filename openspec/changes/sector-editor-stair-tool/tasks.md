# Tasks

## 1. Модель: `build_stair` в `client/sector_editor.py`

- [x] 1.1 Константы: `STAIR_RISE_DEFAULT = 16`, `STAIR_RISE_MAX = STEP_HEIGHT`,
      `STAIR_MAX_STEPS = 64`, `STAIR_MIN_RUN`, `STAIR_POINT_TOL`,
      `STAIR_FACE_TEX = "wall"`; импорт `math`.
- [x] 1.2 Приватные помощники: `_line_param` (проекция + расстояние, `None` вне
      отрезка), `_nearest_stair_hit` (поиск стены по **сырому** клику, привязка
      уже проекции), `_stair_segments_cross`, `_split_span` (расщепление края
      через `split_line_at`, с переиспользованием вершины на конце отрезка).
- [x] 1.3 Валидация входа без мутаций: ровно 4 точки, все различны, каждая на
      стене в пределах допуска, обе линии — односторонние стены, полы не равны.
- [x] 1.4 Разбиение на пары: перебор трёх разбиений, берётся первое, где обе
      точки пары на одной стене, а стены разные. Порядок клика не задаёт пару.
- [x] 1.5 Спаривание: точки каждой стены сортируются по `t`; рельсы
      `a_far↔b_near` и `a_near↔b_far`. Самопересечение квада отвергается с
      подсказкой `Flip`. Выбор «по площади» + нормализация CCW — **неверно**,
      см. design.md.
- [x] 1.6 Высоты: `N = max(1, ceil(|Δ|/clamp(rise,1,STEP_HEIGHT)))`, интерполяция
      к **верхнему** сектору (фаза не зависит от порядка клика), высоты не
      привязываются к сетке, потолок через `clamp_sector_heights`,
      фактический `max_rise` перепроверяется против `STEP_HEIGHT`.
- [x] 1.7 Сборка: цепи `p`/`q` через `lerp`; грань `q_{i+1}→p_{i+1}` с
      **front = нижняя ступень**, back = верхняя; рельсы по участкам, front =
      ступень, back = сектор снаружи либо `-1`; крайние отрезки получают `back`
      стороны ступени, `front` остаётся у наружного сектора.
- [x] 1.8 Атомарность: всё внутри `begin_batch()`/`end_batch()`; проверка
      `has_polygon` по каждому сектору, который был жив до операции, и по каждой
      новой ступени; при провале — `_apply_diff(forward=False)` по
      `make_diff(before, after)`.
- [x] 1.9 Fallback: при провале открытых рельсов — повтор с односторонними
      рельсами; при повторном провале — откат и текст ошибки.
- [x] 1.10 Лимиты: `N > STAIR_MAX_STEPS` и слишком короткие подступ/ширина
      отвергаются; точки вне сетки допустимы.

## 3. Тесты: `smoke_sector_stairs.py`

- [x] 3.1 Геометрия: все ступени имеют замкнутый полигон, лежат в шахте,
      ничего не разрушено вокруг.
- [x] 3.2 Высоты: ступени 16/32/48/64, последняя = пол верхнего сектора, любой
      перепад ≤ `STEP_HEIGHT`.
- [x] 3.3 Порог: без соседа рельсы сплошные (`solid_rails`), с соседом ровно те
      участки, что обращены к нему, становятся порталами, а контур соседа жив.
- [x] 3.4 Отказ: плохая четвёрка (меньше 4 точек / вне стен / одна стена /
      равные полы / нулевая ширина / двусторонний край / слишком много ступеней)
      не меняет карту побайтово, не оставляет запись истории и возвращает текст.
- [x] 3.5 Порядок клика не меняет лестницу: те же уровни и те же полигоны при
      четырёх перестановках точек.
- [x] 3.6 Исключение в середине сборки откатывается: подмена `_split_span` на
      бросающую `ValueError` не оставляет геометрии и не даёт запись истории.
- [x] 3.7 `rise` зажимается в `STEP_HEIGHT`, число ступеней ограничено.
- [x] 3.8 История: одна операция = одна запись; `undo`/`redo` восстанавливают
      карту побайтово.
- [x] 3.9 UI: `K_6`, четыре клика мышью, `Esc` (сброс без выхода, затем выход),
      смена инструмента сбрасывает точки, кнопка панели; кнопки не пересекаются
      и лежат в панели при трёх размерах окна.
