# Tasks

## 1. Модель: `build_stair` в `client/sector_editor.py`

- [ ] 1.1 Константы: `STAIR_RISE_DEFAULT = 16`, `STAIR_MAX_STEPS`,
      `STAIR_TREAD_TEX`/рисуем грань через `lower`; импорт `math`.
- [ ] 1.2 Приватные помощники: `_point_on_line`, `_line_param`,
      `_signed_area2`, `_sector_beyond` (по знаку векторного произведения, не
      по `front`/`back`), `_ensure_stair_verts` (расщепление края через
      `split_line_at` — только существующие точки на существующих линиях).
- [ ] 1.3 Валидация входа: ровно 4 точки, все различны, первая пара на одной
      линии, вторая пара на другой линии, обе линии — односторонние стены
      (по стороне, найденной `_sector_beyond`), площадь квада ≠ 0.
- [ ] 1.4 Выбор спаривания: из двух кандидатов выбрать простой (бо́льшая
      `|area2|`), нормализовать CCW, вернуть `(s0, s1, e0, e1)`.
- [ ] 1.5 Высоты: `N = clamp(ceil(|Δ|/rise), 1, STAIR_MAX_STEPS)`,
      `floor_h` каждой ступени, последняя = пол верхнего сектора; потолок =
      `min` потолков через `clamp_sector_heights`.
- [ ] 1.6 Сборка: вершины срезов `lerp`, срез `i` — двусторонняя линия
      (front = ступень `i`, back = ступень `i-1`, `lower` на back);
      рельсы — по участкам на ступень, side-снаружи = найденный сектор;
      крайние отрезки получают `back` стороны ступени (front остаётся у
      наружного сектора).
- [ ] 1.7 Атомарность: всё внутри `begin_batch()`/`end_batch()`; проверка,
      что каждый сектор с контуром до операции сохранил контур и каждая
      новая ступень получила свой; при провале — `_apply_diff(forward=False)`
      по `make_diff(before, after)` и текст ошибки.
- [ ] 1.8 Fallback: при провале открытых боков — повтор с односторонними
      рельсами; при повторном провале — откат и ошибка.
- [ ] 1.9 `n`-ступенчатая геометрия не превышает лимитов `MAX_*`; вход вне
      сетки допустим (точки снапятся).
