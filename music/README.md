# music/

Музыка боя. Клиент читает эту папку при запуске и играет найденные треки по
кругу **только во время партии**. Лобби, настройки и редакторы — тишина.

## Расширения

Поддерживаются `.ogg`, `.mp3`, `.wav`, `.flac`, `.opus`. Любые прочие файлы
(в том числе этот `README.md`) игнорируются.

## Когда играет музыка

Только в бою. Любой файл в этой папке — боевой трек; имя роли не играет
(`menu_*` — просто обычное имя). В меню музыка сознательно не играет.

Например:

```
music/E1M1.mp3            # играет в партии
music/boss.mp3            # тоже боевой трек
```

Если треков несколько, следующий выбирается случайно и не совпадает с только
что закончившимся; один трек повторяется по кругу. Если папки нет, она пуста
или звуковой карты нет — клиент работает без музыки.

## Проверить, что музыка слышна

Положите хотя бы один файл в эту папку, запустите клиент и зайдите в партию:

```
run_client.bat --name "Player"
```

Громкость — в настройках (S), строка «Громкость музыки». Значение 0 — тишина
при продолжающемся воспроизведении.

## Звуковые эффекты

Звуки выстрелов, попаданий, подбора, дверей, урона и дэша файлами не задаются:
`client/sfx.py` синтезирует их сам при запуске. Эта папка — только музыка, и
эффектам здесь места нет. Громкость эффектов — строка «Громкость звуков» (S).

## Важно: zipapp-артефакт

`tools/build_client.py` копирует в zipapp-артефакт только пакеты
`client`/`shared`/`engine` (строка 68) — папка `music/` в артефакт **не
попадает**. Собранный релиз играет без музыки, пока рядом с ним не положить
`music/` вручную. Это ожидаемо, а не ошибка.
