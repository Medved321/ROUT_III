# ROUT III

Серверо-ориентированный FPS-шутер в стиле Doom 1 с DDA-raycasting рендерером
(секторный BSP-путь + тайловый DDA). Сервер авторитетно управляет игровым
состоянием (20 ticks/sec, asyncio/UDP); клиент на pygame рендерит мир и
отправляет ввод. Игровой трафик — ненадёжный UDP, управляющие сообщения — по
надёжному каналу (`RELIABLE_DATA`/`ACK`) поверх того же сокета.

Полная техническая спецификация — [`SPEC.md`](SPEC.md); правила разработки и
устройство подсистем — [`AGENTS.md`](AGENTS.md).

## Требования

- Python 3.12 (`py -3.12` в Windows; на Linux/macOS — `python3.12`).
- Зависимости: `pygame` (см. `requirements.txt`). `numpy` — опциональная, но
  рекомендуемая зависимость **клиента** (перспективные флаты через `surfarray`);
  клиент при запуске сам доустанавливает её, а при неудаче останавливается с
  явным сообщением. Сервер всегда работает только на stdlib.

```
py -3.12 -m pip install -r requirements.txt
```

## Запуск

```
run_server.bat                      # сервер на 0.0.0.0:7777
run_client.bat --name "Player"      # клиент (меню → партия → игра)
```

На Linux/macOS — `./run_server.sh` / `./run_client.sh`.

Управление: в режиме «Мышь» (по умолчанию) WASD — движение, мышь — обзор,
ЛКМ — огонь, `Пробел` — дэш, Esc — пауза; в режиме «Трактор» `←`/`→` —
поворот камеры, `Пробел` — огонь, `Левый Shift` — дэш. Подробности и хоткеи
меню — в `AGENTS.md` и на экране лобби.

## Тесты

Smoke-тесты — самодостаточные скрипты `smoke_*.py` в корне; каждый печатает
`... PASSED` и возвращает код 0 при успехе. Прогнать все:

```
py -3.12 tools/run_smoke.py            # все тесты
py -3.12 tools/run_smoke.py combat items   # только совпадающие по имени
```

Отдельный тест запускается напрямую:

```
py -3.12 smoke_combat.py
```

Проверка границы движка (`engine/` не должен зависеть от `client`/`server`):

```
py -3.12 tools/check_engine_imports.py
```

## Структура

```
server/    авторитетный сервер (asyncio UDP, лобби + партии); stdlib-only
client/    pygame-клиент: меню-лобби, HUD, bridge-адаптер движка, редакторы
engine/    рендер-ядро (DDA/BSP, фреймбуфер, качества); автономный пакет
shared/    протокол (struct), ECS-компоненты, карта (.mt1/.json), надёжный канал
assets/    карты/текстуры; maps/ — карты редактора; skins/ — спрайты
releases/  версионные артефакты клиента + latest.txt (авто-обновление)
tools/     сборка клиента, проверка границы движка, прогон тестов
openspec/  спека проекта (config.yaml, specs/, changes/)
```

## Сборка релиза клиента

```
py -3.12 tools/build_client.py --version 1.1.0 --set-latest
```

Собирает zipapp в `releases/`, считает `sha256` и обновляет `latest.txt`.
Клиент при подключении сверяет версию из `HELLO_ACK` и при расхождении
предлагает обновиться.
